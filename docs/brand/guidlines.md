# 🎼 **Lead Orchestra — Brand Identity Guide**

*A modern open-source identity for scraping, enrichment & automation infrastructure.*

---

# 1️⃣ **Brand Essence**

### **Brand Purpose**

To make **data acquisition, enrichment, and automation accessible to every builder** — developers, founders, and operators — without enterprise barriers.

### **Brand Promise**

Lead Orchestra gives you **clarity, speed, and control** over your lead generation pipeline, from scraping → enrichment → orchestration.

### **Brand Keywords**

* Technical
* Open-source
* Modular
* Clean
* Precise
* Developer-first
* Ethical & compliant data workflows
* Modern automation stack

### **Brand Tone**

Styled for **engineers, founders, and systems thinkers**:

* Clear, direct, minimal words
* Highly structured content
* Trust-building, not hype
* No “salesy” language
* Same tone as Stripe, GitHub, Vercel, Supabase

---

# 2️⃣ **Logo Usage**

### **Primary Logo**

Text-based wordmark: **Lead Orchestra**

* Typeface: Inter / Söhne / Geist
* Weight: SemiBold or Bold
* Letter-spacing: +1%
* Capitalization: Title Case

### **Icon Mark (for small areas)**

A minimal symbol representing:

* **Nodes + edges (automation graph)**
* **Conductor / orchestration metaphor**
* **Three stacked lines** (scrape → enrich → automate)

The icon should be usable at 24px.

### **Clear Space**

Leave 0.5× logo height on all sides.

### **Do Not:**

* Add gradients
* Add shadows
* Stretch or warp
* Use “LO” unless the icon is designed for it

---

# 3️⃣ **Color System**

Lead Orchestra uses a **technical, modern, black-grey-blue spectrum**, distinct from Deal Scale’s real-estate palette.

## 🎨 **Primary Palette**

| Name                | Hex     | Usage                                 |
| ------------------- | ------- | ------------------------------------- |
| **Orchestra Black** | #0C0C0D | Backgrounds, headers                  |
| **Signal Blue**     | #006CFF | Links, accents, highlights            |
| **Automation Teal** | #1BC9C9 | Secondary accents, technical elements |
| **Graph White**     | #F9FAFB | Light mode backgrounds                |

## 🎨 **Neutral Greys**

| Name        | Hex     | Usage             |
| ----------- | ------- | ----------------- |
| Neutral 900 | #111113 | Title text        |
| Neutral 700 | #3A3A3C | Body text         |
| Neutral 500 | #71717A | Subtext, metadata |
| Neutral 300 | #D1D5DB | Dividers          |
| Neutral 100 | #F3F4F6 | Surfaces          |

## 🎨 **Functional Colors**

| Type    | Hex     | Use Case                       |
| ------- | ------- | ------------------------------ |
| Success | #4ADE80 | Workflow success, ready states |
| Warning | #FACC15 | Rate limits, proxy warnings    |
| Error   | #EF4444 | Scraper failures               |

### **Brand Mood**

* High contrast
* Clean
* Technical
* No pastel tones
* Minimal gradients unless subtle

---

# 4️⃣ **Typography**

Lead Orchestra typography must feel **developer-native**, readable, and grid-perfect.

### **Primary Font**

**Inter** (Open-source)

* H1: 48–64px / SemiBold
* H2: 32–40px / Medium
* H3: 24–28px / Medium
* Body: 16–18px / Regular
* Code: 14px / Mono (JetBrains Mono or IBM Plex Mono)

### **Secondary Font (Optional)**

**Geist Sans** by Vercel
Used for hero sections or marketing pages.

### **Monospace Usage**

For anything technical:
`pip install` • API keys • YAML • JSON • CLI commands

# 5️⃣ **Visual System**

### **UI/Website Style**

* Full-width, spacious grids
* Sections divided with thin grey lines (#D1D5DB)
* Iconography: thin-line stroke style
* Micro-animations only (fade, slide, pulse)
* No drop shadows (unless extra subtle)

### **Illustration Style**

* Abstract geometric shapes
* Node ↔ edge networks
* Browser windows
* Data tables & automation flows

### **Photography**

Not recommended unless showing:

* Product screens
* Terminal windows
* Cloud diagrams

# 7️⃣ **Component Guidelines (for Web/App)**

### **Buttons**

* Primary: `#006CFF` blue with white text
* Radius: 6–8px
* Hover: +8% brightness
* Icons: optional, thin-line style

### **Frames / Cards**

* Border: `1px solid #E5E7EB`
* Background: white or `#0C0C0D` (dark mode)
* Padding: 24–32px
* Shadow: none or ultra-soft

### **Tables**

* Stripe rows
* Use monospace for data
* Pagination for large datasets

### **Code Blocks**

Dark mode preferred:

```
background: #0C0C0D;
color: #F9FAFB;
border-radius: 6px;
padding: 16px;
```

### **Lead Orchestra**

Scraping → Data Acquisition → Normalization → Export

### **Deal Scale**

Enrichment → AI → Scoring → Outreach → CRM Sync

**Positioning Relationship:**
Lead Orchestra = the data pipeline
Deal Scale = the intelligence & activation engine

---

# 9️⃣ **Do + Don’t**

### **Do**

* Keep tone technical & concise
* Use consistent spacing and typography
* Keep brand monochrome with blue accents
* Make documentation the hero

### **Don’t**

* Use cartoonish illustrations
* Overuse gradients
* Use bright, saturated colors
* Use emojis in product UI (emojis fine in GitHub readmes)
